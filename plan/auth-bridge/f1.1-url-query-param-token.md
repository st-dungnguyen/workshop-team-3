# Implementation Plan: F1.1 — URL Query Param Token Reception

**Spec:** [f1.1-url-query-param-token.md](../../spec/auth-bridge/f1.1-url-query-param-token.md)
**Epic plan:** [_epic-E1-auth-bridge.md](./_epic-E1-auth-bridge.md)

---

## 1. Responsibility

F1.1 is one of two extraction methods inside `AuthBridgeService`. It reads from `window.location.search` exactly once on mount. The result (token string or `null`) is handed to the validation flow (F1.3).

This is **not a standalone feature** — it is implemented as a method inside `AuthBridgeService` and called by `useAuthBridge`.

---

## 2. Implementation

### File: `src/app/core/auth/services/auth-bridge.service.ts`

```typescript
extractFromUrlParam(): string | null {
  const params = new URLSearchParams(window.location.search);
  const token = params.get('token');
  return token && token.trim().length > 0 ? token : null;
}
```

- Uses `URLSearchParams` (built-in, handles URL decoding automatically — satisfies GUD-101).
- Returns `null` for missing, empty, or whitespace-only values (satisfies REQ-103, AC-102, AC-103).
- Called **once** at mount inside `useAuthBridge` (satisfies CON-101).
- No logging of the returned value (satisfies SEC-101).

### File: `src/app/core/auth/hooks/useAuthBridge.ts`

```typescript
useEffect(() => {
  const urlToken = authBridgeService.extractFromUrlParam();
  if (urlToken) {
    tokenReceivedRef.current = true;
    handleValidate(urlToken);
    return; // URL param wins — skip bridge listener setup below
  }
  // ... register JS bridge listener (F1.2)
}, []);
```

`tokenReceivedRef` is a `useRef<boolean>(false)` that acts as the "first wins" lock between channels.

---

## 3. Acceptance Criteria Mapping

| AC | How it's met |
|---|---|
| AC-101 | `extractFromUrlParam()` returns the token; `handleValidate()` is called; loading screen renders |
| AC-102 | `params.get('token')` returns `null` → method returns `null` → hook continues to JS bridge listener |
| AC-103 | `token.trim().length > 0` check ensures empty string → `null` |
| AC-104 | `URLSearchParams.get()` decodes percent-encoded values automatically |

---

## 4. Out-of-scope (do not implement)

- Stripping `?token` from the URL bar after extraction — no address bar in WebView, no action needed.
- Watching for URL changes after initial load — CON-101 forbids it.
