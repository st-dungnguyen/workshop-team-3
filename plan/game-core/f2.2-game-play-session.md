## 2. Game Service

### File: `src/app/shared/services/game.service.ts`

```typescript
export class GameService {
  private api = new ApiService();

  async play(campaignId: string): Promise<PlayResult> {
    return this.api.post<PlayResult>([ENDPOINT.game.play], { campaignId });
  }
}
```

Error mapping (done in `useGameSession`, not the service):
- 403 + `ALREADY_PLAYED` → `alreadyPlayed` inline state
- 5xx / network → `serverError` inline state (retry, session not consumed)

## 3. useGameSession Hook

### File: `src/app/pages/game/hooks/useGameSession.ts`

```typescript
type InlineError = 'serverError' | 'alreadyPlayed' | null;

interface UseGameSessionReturn {
  sessionState: SessionState;
  outcome: GameOutcome | null;
  inlineError: InlineError;
  handlePlayInitiated: () => void;    // called by variant when player acts
  handleAnimationComplete: () => void; // called by variant when animation ends
  handleRetry: () => void;            // called by error UI
}
```

State transitions:
```
handlePlayInitiated()
  → setSessionState('initiated')
  → call gameService.play(campaignId)
  → on success: setOutcome(result.outcome), setSessionState('revealing')
  → on 403 ALREADY_PLAYED: setInlineError('alreadyPlayed'), setSessionState('pending')
  → on 5xx: setInlineError('serverError'), setSessionState('pending')

handleAnimationComplete()
  → setSessionState('completed')

handleRetry()
  → setInlineError(null)
  → (session stays 'pending', player can try again)
```

`pending` is the only state where `handlePlayInitiated` has any effect — all other calls are ignored (satisfies VAL-211).

## 5. Scratch Card Variant

### File: `src/app/pages/game/components/ScratchCard.tsx`

**Interaction:** Canvas-based scratch gesture using `pointer` events (works on touch + mouse).

**Auto-complete threshold:** Reveal auto-completes when ≥60% of pixels are scratched (center of the REQ-232 range of 50–70%).

**Implementation sketch:**
```typescript
const ScratchCard = ({ outcome, sessionState, onPlayInitiated, onAnimationComplete }: GameVariantProps) => {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const scratchedRef = useRef(0); // percentage scratched

  // Draw scratch layer on mount
  useEffect(() => {
    if (!canvasRef.current) return;
    const ctx = canvasRef.current.getContext('2d');
    // fill with opaque scratch surface texture
    ctx.fillStyle = '#c8a97e'; // warm parchment tone
    ctx.fillRect(0, 0, CARD_W, CARD_H);
  }, []);

  const handleScratch = (e: PointerEvent) => {
    if (sessionState !== 'pending') return;  // VAL-211

    // Erase pixels at pointer position (destination-out composite)
    // Calculate % of transparent pixels
    // If first scratch → call onPlayInitiated()
    // If scratchedRef.current >= 60 → auto-complete reveal → call onAnimationComplete()
  };

  return (
    <div className="scratch-card">
      <div className="scratch-card-surface">
        {/* Outcome layer beneath */}
        <div className="scratch-card-result" data-outcome={outcome}>
          {/* Win/lose symbol — hidden until scratch reveals it */}
        </div>
        {/* Scratch canvas on top */}
        <canvas ref={canvasRef} onPointerMove={handleScratch} onPointerDown={handleScratch} />
      </div>
      <p className="scratch-card-instruction">{t('scratch.instruction')}</p>
    </div>
  );
};
```

**Key rules:**
- `onPlayInitiated()` is called on the FIRST scratch event when `sessionState === 'pending'`
- Outcome is only revealed visually after `setOutcome` arrives from the shell (once `sessionState === 'revealing'`) — the canvas erase happens immediately but the underlying result image only renders when `outcome` is non-null
- `onAnimationComplete()` is called after auto-complete (CSS transition ends on full reveal)

## 6. Flip Card Variant

### File: `src/app/pages/game/components/FlipCard.tsx`

**Layout:** 3 face-down cards in a row. Player taps one → it flips to reveal outcome. Other two dim.

**State:**
```typescript
const [selectedIndex, setSelectedIndex] = useState<number | null>(null);
```

**Interaction:**
```typescript
const handleCardTap = (index: number) => {
  if (sessionState !== 'pending') return;        // VAL-211
  if (selectedIndex !== null) return;            // REQ-245: only first tap counts
  setSelectedIndex(index);
  onPlayInitiated();                             // → shell calls backend
};
```

**Reveal:**
```typescript
// When sessionState transitions from 'revealing' → outcome is non-null
// Play flip animation on selectedIndex card
// After animation ends (onTransitionEnd / useEffect on sessionState):
//   call onAnimationComplete()
```

**Remaining cards:** Once `selectedIndex` is set, the other cards get class `flip-card-item-dimmed` (opacity + pointer-events: none). They do NOT reveal an outcome — they are decorative end-of-round signals only (REQ-244).

**Implementation sketch:**
```typescript
const FlipCard = ({ outcome, sessionState, onPlayInitiated, onAnimationComplete }: GameVariantProps) => {
  const [selectedIndex, setSelectedIndex] = useState<number | null>(null);
  const CARD_COUNT = 3;

  const handleCardTap = (index: number) => {
    if (sessionState !== 'pending' || selectedIndex !== null) return;
    setSelectedIndex(index);
    onPlayInitiated();
  };

  // When animation ends on the flipped card
  const handleFlipEnd = () => {
    onAnimationComplete();
  };

  return (
    <div className="flip-card-board">
      <p className="flip-card-instruction">{t('flip.instruction')}</p>
      <div className="flip-card-row">
        {Array.from({ length: CARD_COUNT }, (_, i) => (
          <div
            key={i}
            className={[
              'flip-card-item',
              selectedIndex === i && sessionState === 'revealing' ? 'flip-card-item-flipping' : '',
              selectedIndex !== null && selectedIndex !== i ? 'flip-card-item-dimmed' : '',
            ].join(' ')}
            onClick={() => handleCardTap(i)}
            onTransitionEnd={selectedIndex === i ? handleFlipEnd : undefined}
          >
            <div className="flip-card-item-inner">
              <div className="flip-card-item-front" /> {/* back face */}
              <div className="flip-card-item-back" data-outcome={outcome} /> {/* front face */}
            </div>
          </div>
        ))}
      </div>
    </div>
  );
};
```

## 7. GameShell Container

### File: `src/app/pages/game/containers/GameShell.tsx`

```typescript
const GameShell = () => {
  const { sessionState, outcome, inlineError, handlePlayInitiated, handleAnimationComplete, handleRetry } = useGameSession();

  if (sessionState === 'completed') {
    return <GameResult outcome={outcome!} />;
  }

  if (inlineError === 'alreadyPlayed') {
    return <GameAlreadyPlayed />;   // inline state, not a route
  }

  return (
    <div className="game-shell">
      {inlineError === 'serverError' && (
        <GameServerError onRetry={handleRetry} />
      )}
      <VariantRenderer
        outcome={outcome}
        sessionState={sessionState}
        onPlayInitiated={handlePlayInitiated}
        onAnimationComplete={handleAnimationComplete}
      />
    </div>
  );
};
```

`GameResult` and inline error states are rendered by `GameShell` — not separate routes. This prevents direct URL navigation to result/error states without an active session.

## 9. Acceptance Criteria Mapping

| AC | How it's met |
|---|---|
| AC-211 | `handlePlayInitiated()` transitions to `'initiated'`; board locked by `sessionState !== 'pending'` guard |
| AC-212 | Backend returns `win` → `setOutcome('win')` → `setSessionState('revealing')` → variant renders win animation |
| AC-213 | Same for `lose` |
| AC-214 | 5xx → `setInlineError('serverError')`, `setSessionState('pending')` → not counted as played |
| AC-215 | `handleAnimationComplete()` → `setSessionState('completed')` → `GameShell` renders `GameResult` |
| AC-231–233 | Canvas auto-complete at 60% threshold; `onPlayInitiated` on first scratch event |
| AC-241–244 | Flip card tap guard; CSS 3D flip; remaining cards dimmed |
