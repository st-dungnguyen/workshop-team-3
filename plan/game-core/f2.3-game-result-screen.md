## 1. Responsibility

`GameResult` is a shared container rendered by `GameShell` when `sessionState === 'completed'`. It is the same for every game variant. It does not live at a separate route — it is conditionally rendered within the game route.

The win path delegates all reward/coupon logic to E3. `GameResult` only:
- Shows the outcome visually
- Provides CTAs
- Disables CTAs while E3 is in flight
- Displays `reward.claimError` if E3 fails

The lose path shows a friendly message and a close CTA.

---

## 2. File

### `src/app/pages/game/containers/GameResult.tsx`

```typescript
interface GameResultProps {
  outcome: GameOutcome;
}

const GameResult = ({ outcome }: GameResultProps) => {
  if (outcome === 'win') return <WinResult />;
  return <LoseResult />;
};
```

`WinResult` and `LoseResult` are presentational sub-components within the same file (not exported separately — they are only used by `GameResult`).

## 3. WinResult

**State owned by `GameResult` for the win path:**
```typescript
const [ctaState, setCtaState] = useState<'idle' | 'loading' | 'error'>('idle');
const [selectedIntent, setSelectedIntent] = useState<'claim' | 'useNow' | null>(null);
```

**CTA handler:**
```typescript
const handleCta = async (intent: 'claim' | 'useNow') => {
  if (ctaState === 'loading') return;  // CON-303: no double-tap
  setSelectedIntent(intent);
  setCtaState('loading');
  try {
    await rewardService.recordWinAndNavigate(intent); // E3 — handles coupon + AppLink
  } catch {
    setCtaState('error');
  }
};
```

**Render:**
```tsx
<div className="game-result-win">
  <div className="game-result-win-illustration" />  {/* celebratory visual */}
  <p className="game-result-win-title">{t('result.win.title')}</p>
  <p className="game-result-win-body">{t('result.win.body')}</p>
  <div className="game-result-win-coupon" />        {/* coupon card placeholder */}

  {ctaState === 'error' && (
    <p className="game-result-win-error">{t('result.claimError')}</p>
  )}

  {/* "Use Now" — primary CTA (GUD-303: filled/prominent) */}
  <button
    className="btn-primary game-result-cta"
    disabled={ctaState === 'loading'}
    onClick={() => handleCta('useNow')}
  >
    {t('result.useNow')}
  </button>

  {/* "Claim Coupon" — secondary CTA (GUD-303: outlined/subdued) */}
  <button
    className="btn-secondary game-result-cta"
    disabled={ctaState === 'loading'}
    onClick={() => handleCta('claim')}
  >
    {t('result.claimCoupon')}
  </button>
</div>
```

**Note on E3:** `rewardService.recordWinAndNavigate(intent)` is E3's responsibility and is a stub for now. For the E2 demo, this function can log the intent and resolve immediately. E3 will replace the stub with the real coupon API call + AppLink navigation.

## 4. LoseResult

```tsx
<div className="game-result-lose">
  <div className="game-result-lose-illustration" />
  <p className="game-result-lose-title">{t('result.lose.title')}</p>
  <p className="game-result-lose-body">{t('result.lose.body')}</p>
  <button
    className="btn-primary game-result-cta"
    onClick={() => { window.location.href = `${window.location.origin}/close`; }}
  >
    {t('result.close')}
  </button>
</div>
```

No replay button (REQ-313). The close navigates to `{origin}/close` per the WebView closing convention in CLAUDE.md.

---

## 5. Appearance Timing

`GameShell` transitions to `completed` inside `handleAnimationComplete()`, which fires immediately when the variant signals its animation is done. `GameResult` is rendered synchronously on that state change — no async gap (REQ-321).

## 8. Acceptance Criteria Mapping

| AC | How it's met |
|---|---|
| AC-301 | `outcome === 'win'` → `WinResult` renders title, coupon visual, both CTAs |
| AC-302 | Either CTA tap → `ctaState = 'loading'` → both buttons `disabled` → E3 called with intent |
| AC-303 | E3 throws → `ctaState = 'error'` → `claimError` message shown; win content still visible |
| AC-304/305 | E3 success → `rewardService` handles AppLink (E3 responsibility) |
| AC-306 | `if (ctaState === 'loading') return` guard prevents second request |
| AC-311 | `outcome === 'lose'` → `LoseResult` renders friendly message + close button; no replay |
| AC-312 | Close CTA → `window.location.href = origin/close` |
| AC-321 | `GameShell` renders `GameResult` synchronously on `completed` state — no async gap |
| AC-322 | All strings from `game.json` via `useTranslation('game')` |
| AC-323 | Same `GameResult` component rendered for both variants — no variant-specific logic |
