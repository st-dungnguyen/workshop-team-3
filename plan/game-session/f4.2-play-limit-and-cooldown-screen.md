## Component

`PlayLimitScreen` — defined in `GameShell.tsx` (not exported). Rendered by `GameShell` when `useEligibilityCheck` returns `ineligible`. Also used as a fallback inside `GameContent` when `POST /game/play` returns 403 `ALREADY_PLAYED` mid-session.

```tsx
<PlayLimitScreen nextPlayAt={string | null} />
```

### nextPlayAt display logic

```typescript
const formatNextPlayAt = (iso: string, lng: string): string =>
  new Date(iso).toLocaleString(lng === 'ja' ? 'ja-JP' : 'en-US', {
    month: 'long', day: 'numeric', weekday: 'short',
    hour: '2-digit', minute: '2-digit',
  });
```

Displayed via i18n interpolation: `t('alreadyPlayed.nextPlayAt', { date: formatNextPlayAt(...) })`.
Falls back to `t('alreadyPlayed.comeBackSoon')` when `nextPlayAt` is null.

### Close CTA

```typescript
window.location.href = `${window.location.origin}/close`;
```

Per `applinks.md` — both iOS and Android intercept `{webViewHost}/close`.
